BDSS · 电话爬虫
特性 使用 引擎 API GitHub
🐍 Python · Playwright · 多引擎

公司联系电话爬虫

基于 DrissionPage + Playwright 双引擎，支持百度、谷歌、必应、搜狗、百度地图多引擎搜索，自动去重、地理校验、CSV 导出。

📦 GitHub 📖 快速开始 🔌 API

核心特性

🔍

多引擎搜索

百度、必应、搜狗、谷歌、百度地图 POI 五引擎，支持 --all 合并去重

🛡️

反爬对抗

注入 playwright-stealth、模拟真人浏览行为、自动验证码检测与恢复

⚡

并行搜索

ThreadPoolExecutor 同时跑 3 个引擎，速度提升 3 倍，单个失败不中断

📍

地理校验

自动检测页面中出现的城市，校验电话区号是否匹配，标记可疑号码

🧩

搜索扩展

电话不足时自动补充 "公司名+电话/联系方式" 搜索，调用百度地图 POI API

📄

多格式导出

JSON / CSV / Excel 输出，带来源 URL、标题、可信度、警告标记

🗄️

SQLite 缓存

24 小时缓存已查公司，重复查询直接返回，--no-cache 强制刷新

🌐

Web 界面 + API

内嵌 HTML 表单，浏览器打开即搜；REST API 带可选的 Token 认证

🚀

一键部署

Docker / Render / Railway 模板，开箱即用

快速开始

📦 安装

# 克隆仓库
git clone https://github.com/gaokkuan-1023/bdss.git
cd bdss

# 安装依赖
pip install -r requirements.txt
python -m playwright install chromium

🔍 基础搜索

# 单个公司（默认百度引擎）
python main.py "深圳腾讯计算机系统有限公司"

# 指定引擎 + 详细输出
python main.py "阿里巴巴" --engine bing --verbose

# 五引擎合并搜索（推荐）
python main.py "山东华派集团有限公司" --all --max 5 --delay 1500 -v -o result.json

📋 批量搜索

# companies.txt（每行一个公司名）
python main.py -f companies.txt --all --delay 2000 --output ./results/

🐳 Docker

docker build -t bdss .
docker run --rm bdss "字节跳动" --all --delay 1000

参数说明

参数说明默认
--engine / -e搜索引擎选择baidu
--all / -a多引擎合并搜索—
--max / -m每引擎打开结果数5
--delay请求间隔（毫秒）0
--output / -o输出 JSON 路径当前目录
--csv同时导出 CSV—
--proxy代理地址—
--verbose / -v详细信息（DEBUG 级别）—
--visible显示浏览器窗口（调试）—

搜索引擎支持

引擎类名反爬难度需要代理说明
baidu BaiduSearch 中 否 主引擎，含手机版补充、多页翻页、验证码恢复
google GoogleSearch 高 是 境外搜索，需科学上网
bing BingSearch 低 否 必应中文版，结果稳定
sogou SogouSearch 中 否 搜狗搜索
baidumap query_map_poi 低 否 百度地图 POI（API + 页面双通道）

HTTP API 服务

🔌 启动服务

pip install flask          # 首次安装
python api_server.py       # 默认 :5000

📡 接口

POST /api/search — 搜索公司电话

# 请求
curl -X POST http://localhost:5000/api/search \
  -H "Content-Type: application/json" \
  -d '{
    "company": "深圳腾讯",
    "engine": "all",
    "max_results": 5,
    "delay": 1500
  }'

# 响应
{
  "success": true,
  "data": {
    "company": "深圳腾讯",
    "phones": ["0755-86013388", "400-670-0700"],
    "phone_count": 2,
    "engine": "baidu + bing + sogou",
    "geo_check": { ... }
  }
}

🏥 健康检查

# 请求
curl http://localhost:5000/api/health

# 响应
{ "status": "ok", "version": "1.0.0" }
