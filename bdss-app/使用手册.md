# BDSS 批量获客系统 — 使用手册

## 一、系统简介

BDSS（Business Data Search System）是一套面向工业品销售/B2B 获客场景的数据工具，帮您自动搜索目标公司的联系方式，让销售团队专注于打电话，而不是花时间在网上搜电话。

### 核心能力

| 功能 | 说明 |
|------|------|
| **批量搜电话** | 上传公司名单 → 自动全网搜电话 → 下载结果 |
| **招标监控** | 自动扫描招标网站 → 提取采购方电话 → 通知你 |
| **公司详情** | 点击采购方名称 → 查看该公司所有招标记录和电话 |

---

## 二、启动与访问

```bash
# 1. 配置 API Key（必填）
cd ~/bdss-app
echo 'BAIDU_MAP_AK=你的百度地图AK' >> .env

# 2. 启动服务
python app.py

# 3. 打开浏览器
# http://localhost:5300
```

### 登录后看到的页面

```

├─────────────────────────────────────────────────┤

└─────────────────────────────────────────────────┘
```

## 三、功能一：搜电话

**用途：** 手头有一批目标公司名单，想查他们的联系电话。

### 操作步骤

```
1. 从企查查/天眼查导出公司名单为 Excel
   → 确保有一列叫「公司名称」

2. 打开 http://localhost:5300
   → 点击「上传公司名单」
   → 选择你的 Excel 文件

3. 系统自动识别公司数量
   → 显示预览
   → 点击「开始搜索」

4. 等待搜索完成
   → 每家公司约 2 秒
   → 50 家公司约 2 分钟

5. 下载结果
   → 点击「下载结果 Excel」
   → 打开 Excel，可以看到每家公司的电话
```

### Excel 输入格式

| 公司名称 | 地区 | 备注 |
|---------|------|------|
| 华能国际电力股份有限公司德州电厂 | 山东 | — |
| 万华化学集团股份有限公司 | 烟台 | — |
| 山东钢铁集团有限公司 | 济南 | — |

> 第一列表头必须包含「公司」或「名称」字样，系统会自动识别。

### 输出结果说明

| 列 | 说明 |
|----|------|
| 公司名称 | 原始输入 |
| 搜到电话 | 从百度地图等来源找到的电话，多个用 `|` 分隔 |
| 电话数量 | 找到的电话个数（0 表示未找到） |
| 其他列 | 原始输入的附加信息 |

## 四、功能二：招标监控

**用途：** 自动扫描招投标网站，找到新的采购需求，拿到采购方的联系方式。

### 操作步骤

```
1. 打开 http://localhost:5300/monitor

2. 点击「立即扫描」
   → 系统自动扫描中国政府采购网 + 招标采购导航网
   → 约 1 分钟完成

3. 查看结果
   → 最新线索列表：包含标题、采购方、联系人、电话
   → 扫描日志：显示每次扫描结果

4. 标记已联系
   → 点击线索右侧的「已联系」按钮
   → 标记后不再显示为红色
```

### 自动化功能

- **定时扫描**：每小时自动扫描一次，新线索会保存到数据库
- **微信通知**：配置后，扫描到新线索会推送到微信
- **导出 Excel**：点击「导出 Excel」下载所有招标线索

### 公司详情

点击招标线索中的采购方名称（蓝色文字），可以查看该公司的：
- 所有相关的招标记录
- 所有找到的联系方式（联系人、电话、邮箱）

## 五、搜索范围

### 电话搜索数据源

| 数据源 | 覆盖 | 说明 |
|--------|------|------|
| 百度地图 POI | ~60% | 百度地图上注册的公司电话 |
| 顺企网 | ~10% | 企业黄页补充 |

> 找不到电话的公司通常是：没有在百度地图注册、或者注册信息不包含电话。

### 招标监控数据源

| 数据源 | 每次扫描 | 说明 |
|--------|---------|------|
| 中国政府采购网 | ~8 条 | 全国政府采购招标信息 |
| 招标采购导航网 | ~4 条 | 聚合招标信息 |

> 招标数据覆盖全国，关键词包括：水处理药剂、阻垢剂、杀菌剂、循环水处理等 14 个行业词。

## 六、配置说明

### 1. 百度地图 API Key（必填）

电话查询的核心数据源，免费申请：

```
1. 打开 https://lbsyun.baidu.com/apiconsole/key
2. 登录百度账号 → 创建应用
3. 选择「服务端 API」→ IP 白名单填 0.0.0.0/0
4. 获取 AK 字符串
5. 在 .env 文件中配置：
   BAIDU_MAP_AK=你的AK
```

### 2. 微信通知（可选）

新线索自动推送到微信：

```
1. 打开 https://sct.ftqq.com
2. 扫码登录 → 复制 SendKey
3. 在 .env 文件中配置：
   BDSS_WECHAT_SENDKEY=你的SendKey
```

### 3. 招标关键词（可选）

在网页上直接配置：

```
1. 打开监控页面 http://localhost:5300/monitor
2. 点击「关键词」按钮
3. 勾选/取消关键词
4. 点击「保存」
5. 下次扫描时生效
```

## 七、常见问题

### Q: 搜索结果显示电话为 0

可能原因：
- 百度地图上没有该公司注册信息
- 公司名称不完整（尝试输入全称）
- 公司是小微企业，未在百度地图登记

### Q: 招标扫描需要多久

约 50-60 秒。因为政府采购网有反爬保护，每次请求需要间隔 3 秒。

### Q: 数据准不准

电话来源于百度地图 POI 数据，准确率约 60%。建议：
- 找到的电话 → 先用着
- 找不到的 → 结合其他渠道补充

### Q: 可以搜索哪些行业

当前关键词配置为水处理/化工/电力行业。如果要换行业，在监控页面点击「关键词」修改即可。

### Q: 如何导入阿里云外呼

下载结果 Excel 后，可以直接导入阿里云外呼系统。格式兼容：
- 公司名 → 客户名称
- 电话 → 联系号码
